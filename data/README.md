# ManganEX Data Directory

This directory contains geological, geographical, and model-related data for the ManganEX pipeline.
To maintain data integrity and reproducibility, please adhere to the following structure:

## Directory Structure

*   **`raw/`**: Unmodified original data files. This directory is strictly **read-only** for data processing scripts. Never modify or overwrite files in this directory. If new raw data is acquired, add it here with a clear timestamp or version.
*   **`processed/`**: Cleaned, transformed, and feature-engineered data ready for machine learning model training or analysis. Files here are generated by scripts in the `backend/app/data_pipeline/` module.
*   **`sample/`**: Demonstration and sample datasets used for testing the data pipeline and backend features. This data should be clearly labeled and not confused with real geological data.
*   **`external/`**: Data obtained from third-party sources (e.g., satellite imagery, external APIs) that might require specialized preprocessing before joining with main datasets.

## Important Note

Always validate data before moving it from `raw/` or `sample/` into `processed/`. Do not perform scientifically unjustified imputation on missing values. Ensure coordinate ranges are valid.
